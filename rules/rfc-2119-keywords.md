# RFC 2119 keywords

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in every instruction loaded in this session (rules, CLAUDE.md and AGENTS.md files, skills, agents, and commands) are to be interpreted as described in RFC 2119 and RFC 8174 when, and only when, they appear in all capitals.
